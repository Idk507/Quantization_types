Granularity Choices: Per Tensor, Per Channel, Per Group. Once you understand the basic operation, the next decision is how many scale factors to use. Per tensor uses one scale for an entire matrix and is cheapest but least accurate. Per channel assigns one scale per output neuron or filter and is the default in almost every serious toolkit today. Per group, also called group wise, splits a row into small blocks such as 32, 64, or 128 elements each with its own scale, and is the granularity used by GPTQ, AWQ, and GGUF.
