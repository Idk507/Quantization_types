QLoRA, Quantization for Fine Tuning. This freezes a backbone in a four bit format called NF4, information theoretically optimal for normally distributed weights, adds a second quantization pass over the quantization constants themselves called double quantization, and trains small low rank adapters in BF16 on top, backpropagating through the frozen quantized weights with the straight through estimator. Learn this once you need to train, not just serve, under a constrained memory budget.
